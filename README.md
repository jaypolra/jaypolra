## Featured Research Release

### [Visual Geometry Grounded Novel-View Acoustic Synthesis](https://github.com/jaypolra/geometry-grounded-nvas)

**CVPR 2026 Workshop** · Purdue University Northwest · UC Irvine · CIVS · San Diego State University

A unified framework for novel-view acoustic synthesis that bypasses explicit 3D visual rendering and costly photogrammetry by grounding spatial audio generation in feed-forward visual geometry.

[![Geometry-Grounded NVAS teaser](https://raw.githubusercontent.com/jaypolra/geometry-grounded-nvas/main/media/teaser_GGNAVS.png)](https://github.com/jaypolra/geometry-grounded-nvas)

**Why it matters**

- Synthesizes binaural audio for novel viewpoints in 3D spaces without target-view image rendering.
- Uses visual geometry features to condition acoustic generation across RWAVS and Replay-NVAS.
- Provides training, evaluation, aggregation, benchmarking, and citation-ready documentation.
