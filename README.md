## About

I like turning research ideas into working systems: models, interfaces, evaluation scripts, and the little engineering details that make a project usable.

My work spans computer vision, multimodal learning, spatial audio, vision-language models, explainable AI, and industrial safety systems. I like projects where the model is only one part of the problem: the full system also has to handle messy inputs, evaluation, deployment constraints, and a user who needs to trust the output.

Currently, my research at **CIVS, Purdue University Northwest** focuses on visual-geometry-grounded audio synthesis, AI-assisted safety monitoring for steel manufacturing environments, and interpretable multimodal systems.

## Research & Projects

| Project | Focus | What it does |
|---|---|---|
| [geometry-grounded-nvas](https://github.com/jaypolra/geometry-grounded-nvas) | **CVPR Workshop 2026** · Audio-Visual Learning | Synthesizes novel-view binaural audio by grounding acoustic generation in feed-forward visual geometry. |
| [ai-hazard-recognition](https://github.com/jaypolra/ai-hazard-recognition) | **AISTech 2026 submission** · Industrial AI Safety | Real-time melt shop hazard monitoring with YOLO26m, DeepSORT, blocker-aware zone logic, and multi-camera dashboarding. |
| [vlm-hazard-reasoning](https://github.com/jaypolra/vlm-hazard-reasoning) | Vision-Language Models · Industrial Safety | Tests whether VLMs can explain plant-specific hazards from alert frames using domain-aware prompting. |
| [vlm-explainer](https://github.com/jaypolra/vlm-explainer) | Explainable AI · VLM Interpretation | Streamlit tool for BLIP token Grad-CAM, region masking, caption changes, and CLIP alignment checks. |
| [candidate-matcher](https://github.com/jaypolra/candidate-matcher) | Applied NLP · Retrieval | ATS-style resume ranking with MiniLM embeddings, cosine similarity, and LLM-generated recruiter summaries. |
